# 🎬 Kids Animation Studio AI

Studio perencanaan produksi animasi anak 3D.

## Fitur Tahap 1
- Membuat konsep cerita anak.
- Menyusun storyboard otomatis.
- Mengatur durasi 3–5 menit.
- Mengatur karakter dan bahasa.
- Persetujuan konsep sebelum produksi.
- Download storyboard dalam format JSON.
